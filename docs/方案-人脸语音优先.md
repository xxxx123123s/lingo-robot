# 人脸 + 语音优先路线（电机后置）

> 你的新优先级：**先让人脸和语音交互跑起来，机器人先不装履带。**
>
> 这条路线先做一台“坐在桌上的桌宠”：能看、能听、能说；电机和履带放到最后。
> 原来的完整硬件/电机方案见 [方案.md](方案.md)，里面的电机部分留到后面再用。

---

## 0. 路线调整

原来的顺序是：

```text
M1 电机 → M2 摄像头 → M3 人脸 → M4 音频 → M5 语音 → M6 联调
```

现在改成：

```text
F0 硬件盘点
 → F1 摄像头 + 人脸检测
 → F2 人脸录入 + 识别
 → F3 音频输入/输出
 → F4 语音对话（先文字，再语音）
 → F5 人脸 + 语音联动（叫出名字、打招呼）
 → F6 网页/外壳
 → 最后：电机 + 履带
```

好处：

- 不需要先买底盘和电机，现有树莓派 + 摄像头就能开始；
- 人脸和语音都可以单独验收，不会互相拖累；
- 机器人不动，调试时更安全，摄像头画面也稳定；
- 以后加履带时，视觉和语音模块已经稳定，只需要接运动控制。

## 1. 你的配置：Pi 4B + 32GB SD

先确认几件事，后面的参数都按这个来：

- **系统用 64 位**：`uname -m` 应该是 `aarch64`。如果显示 `armv7l`，建议重装 64 位 Raspberry Pi OS Bookworm；32 位下部分 Python 轮子/模型会更麻烦。
- **内存**：运行 `free -h`。2GB 也能跑，但建议无桌面运行，语音识别用 Vosk 小模型、对话走云端；4GB 会舒服很多。
- **性能预期**：Pi 4B 跑 640×480 的 YuNet，目标是 **8–15 FPS**。如果低于 8 FPS，改成 480×360，或关掉桌面/浏览器。
- **电源**：Pi 4B 用官方 **5V/3A USB-C** 电源。摄像头 + USB 音频 + Wi-Fi 同时工作时，廉价电源很容易欠压重启；用 `vcgencmd get_throttled` 检查，`0x0` 才正常。
- **散热**：Pi 4B 加散热片/风扇；到 80°C 会降频，帧率会掉。
- **SD 卡**：32GB 够用。系统和模型之外至少留 8–10GB；尽量用 A1/A2 卡，少写日志，避免频繁断电。
- **摄像头**：CSI 排线走 `picamera2`。Camera Module 3（`imx708`）支持自动对焦；Camera Module 2（`imx219`）/1（`ov5647`）是定焦，需要手动调镜头。
- **语音**：Vosk 中文小模型 + 云端大模型/TTS 没问题；不要尝试在 Pi 4B 上跑 7B 本地大模型。

### 需要补什么

#### 必需

| 物品 | 参考价 | 说明 |
|---|---:|---|
| USB 耳麦（麦克风+喇叭一体） | 30–40 元 | 最便宜的语音输入输出方案；Pi 4B 有 3.5mm 孔，但底噪大、不方便，USB 更稳 |
| 大模型 API Key | 按量计费 | DeepSeek / 通义千问，二选一 |

#### 建议

| 物品 | 参考价 | 说明 |
|---|---:|---|
| Pi 4B 散热片/风扇 | 15–30 元 | 视频 + 语音同时跑，温度会高 |
| 官方 5V/3A USB-C 电源 | 已有则 0 元 | 摄像头 + USB 音频同时工作，廉价电源容易重启 |

#### 先不买

- 履带底盘、TB6612、电机电池；
- 舵机云台、OLED、激光雷达；
- 大尺寸屏幕。

你的 CSI 摄像头用 `picamera2`，不要用 OpenCV 的 `cv2.VideoCapture(0)`。人脸脚本里写 `--source picamera` 可以强制走 CSI 后端。

## 3. F1：摄像头 + 人脸检测（先跑这个）

### 3.1 安装 OpenCV

Raspberry Pi OS 推荐用 apt：

```bash
sudo apt update
sudo apt install -y python3-opencv python3-numpy
```

CSI 摄像头还需要：

```bash
sudo apt install -y python3-picamera2
```

检查：

```bash
python3 -c "import cv2; print(cv2.__version__); print(hasattr(cv2, 'FaceDetectorYN'))"
```

最后一行应该是 `True`。如果是 `False`，OpenCV 太旧，改用 pip：

```bash
python3 -m venv --system-site-packages .venv
source .venv/bin/activate
pip install --upgrade -r requirements-face.txt
```

### 3.2 CSI 摄像头先做一次确认

你的摄像头是 CSI 排线，先不要跑人脸脚本，先确认系统能看到它：

```bash
# Raspberry Pi OS Bookworm 新版
rpicam-hello --list-cameras

# 旧版系统如果提示 command not found，用这个
libcamera-hello --list-cameras
```

正常输出会类似：

```text
Available cameras
-----------------
0 : imx708 [4608x2592] (/base/soc/i2c0mux/i2c@1/imx708@1a)
    Modes: 'SRGGB10_CSI2P' : 1536x864 [120.13 fps - (768, 432)/16x16]
```

根据传感器型号判断：

| 型号 | 摄像头 | 对焦 |
|---|---|---|
| `ov5647` | Camera Module 1（5MP） | 定焦 |
| `imx219` | Camera Module 2（8MP） | 定焦，可手动转镜头 |
| `imx708` | Camera Module 3（12MP） | 自动对焦 |

`face_detect.py` 会尝试给 `imx708` 开启连续自动对焦；`ov5647` / `imx219` 是定焦，设置失败会自动跳过。定焦摄像头需要手动转镜头，让人脸在 0.5–1.5 米内最清晰。

拍一张测试照：

```bash
# 新版
rpicam-still -o ~/camera_test.jpg --width 1280 --height 720 -t 2000 -n

# 旧版
libcamera-still -o ~/camera_test.jpg --width 1280 --height 720 -t 2000 -n
```

再用 `picamera2` 确认 Python 能打开：

```bash
python3 -c "from picamera2 import Picamera2; c=Picamera2(); print(c.sensor_resolution); c.close()"
```

如果看不到摄像头：

1. 断电，重新插 CSI 排线；排线金属触点方向别插反，卡扣压紧。
2. Pi 4B 只有一个 CSI 接口；重点检查排线是否插到底、卡扣是否压紧，以及排线是否损坏。
3. 检查 `/boot/firmware/config.txt` 里有没有 `camera_auto_detect=1`。
4. 运行 `sudo raspi-config` → Interface → Camera，确认启用。
5. 更新系统：`sudo apt update && sudo apt full-upgrade`。
6. 看内核日志：`dmesg | grep -iE 'imx219|imx708|ov5647|csi|unicam'`。

### 3.3 运行人脸检测

```bash
python3 scripts/face_detect.py --source picamera --save artifacts/face.jpg
```

第一次运行会自动下载 YuNet 模型到 `models/`（约 230KB）。如果树莓派访问 GitHub 慢，可以手动下载：

```bash
mkdir -p models
curl -L -o models/face_detection_yunet_2023mar.onnx \
  https://raw.githubusercontent.com/opencv/opencv_zoo/main/models/face_detection_yunet/face_detection_yunet_2023mar.onnx
```

常用参数：

```bash
# 指定 CSI 摄像头
python3 scripts/face_detect.py --source picamera --save artifacts/face.jpg

# 指定 USB 摄像头（默认 /dev/video0）
python3 scripts/face_detect.py --source usb --camera 0

# 有桌面环境时显示窗口
python3 scripts/face_detect.py --show

# 只跑 100 帧，方便测试
python3 scripts/face_detect.py --max-frames 100 --save artifacts/face.jpg
```

Pi 4B 如果 640×480 低于 8 FPS，先降分辨率：

```bash
python3 scripts/face_detect.py --source picamera --width 480 --height 360 --save artifacts/face.jpg
```

分辨率降低后，远处小脸会更难检测；先把桌子范围控制在 0.5–1.5 米。

### 3.4 验收标准

- 终端能看到 `FPS` 和 `faces` 数量；
- 0.5–2 米内正脸能稳定框住；
- `artifacts/face.jpg` 里能看到绿色人脸框；
- Pi 4B：640×480 目标 8–15 FPS；如果低于 8 FPS，用 480×360，或关掉桌面/浏览器；
- 连续跑 10 分钟不崩溃。

### 3.5 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `cv2` 没有 `FaceDetectorYN` | OpenCV 太旧 | 升级 OpenCV |
| CSI 摄像头打不开 | 用错后端 | `--source picamera`，不要用 `cv2.VideoCapture(0)` |
| USB 摄像头打不开 | 设备号不对 | `ls /dev/video*`，试 `--camera 1` |
| 画面颜色不对 | RGB/BGR 转换 | 脚本已处理；若仍异常，检查摄像头格式 |
| 帧率很低 | 分辨率太高/CPU 降频 | 640×480，加散热，换 5V/3A 电源 |
| 模型下载失败 | GitHub 网络 | 用上面的 `curl` 手动下载 |

## 4. F2：人脸录入 + 识别

> 先确保 F1 稳定，再做 F2。识别比检测更容易受光照、角度影响。

### 4.1 目标

- 录入 2–3 个人，每人 10 张不同角度/光照的照片；
- 用 SFace 提取 128 维特征，保存到 `faces/<名字>.npz`；
- 实时画面中显示名字，陌生人显示 `unknown`；
- 不在云端保存人脸。

### 4.2 命令

```bash
# 录入（会提示看镜头，自动采集 10 帧）
python3 scripts/face_db.py enroll --name xiaoming

# 识别
python3 scripts/face_db.py recognize --show

# 无桌面环境时保存截图
python3 scripts/face_db.py recognize --save artifacts/recognize.jpg
```

第一次运行 `enroll` 会自动下载 SFace 模型（约 37MB）到 `models/`。如果下载慢，可以按脚本提示用 `curl` 手动下载。

> 如果 F1 还没稳定，先不要录入。检测框都跳来跳去时，采集到的特征质量会很差。

### 4.3 验收标准

- 每个人 10 次测试至少认对 8 次；
- 陌生人不会被叫成某个人；
- 侧脸、强逆光允许失败，但正脸要稳定；
- 阈值先按余弦相似度 `0.363` 试，再按实际校准。

### 4.4 重要提醒

- 这是玩具级识别，**不要用于门禁、支付、身份认证**；
- 人脸特征只存本地，不上传；
- 录入时多换角度和光照，比换更复杂的模型更有效。

## 5. F3：音频输入/输出

### 5.1 买一个 USB 耳麦

最便宜的做法：USB 耳麦（麦克风 + 耳机一体），约 30–40 元。
优点：

- 一个设备同时有麦克风和喇叭；
- Pi 4B 有 3.5mm 孔，但板载音频底噪大；USB 耳麦更稳；
- 调试时不会吵到别人；
- 半双工对话容易实现。

> 如果你已经买了 **INMP441 + MAX98357**：可以接，但 Pi 4B 只有一组 I2S，软件不是即插即用。
> 接线、`googlevoicehat-soundcard` 配置和退路见 [音频-INMP441-MAX98357.md](音频-INMP441-MAX98357.md)。

### 5.2 测试

```bash
# 看设备
arecord -l
aplay -l

# 录 3 秒
arecord -f S16_LE -r 16000 -c 1 -d 3 ~/mic_test.wav

# 回放
aplay ~/mic_test.wav

# 播放测试音
speaker-test -t sine -f 440 -c 1 -l 1
```

如果默认设备不对，用 `-D plughw:CARD,DEVICE` 指定，例如：

```bash
arecord -D plughw:1,0 -f S16_LE -r 16000 -c 1 -d 3 ~/mic_test.wav
```

### 5.3 验收标准

- 回放能听清自己说话；
- 没有明显爆音/持续底噪；
- 录音音量不过小；
- 播放 TTS 时不会把喇叭声录进去（先做半双工）。

## 6. F4：语音对话

### 6.1 先用文字把“大脑”跑通

不要一上来就接麦克风。先确认：

```text
键盘输入 → 大模型 → 终端输出 → （可选）TTS 播放
```

这样 API、人格、回复长度都稳定后，再换语音输入。

### 6.2 选型

| 环节 | 第一版 | 以后升级 |
|---|---|---|
| 语音识别 | Vosk 中文小模型（离线、便宜、够用） | sherpa-onnx SenseVoice |
| 对话 | DeepSeek / 通义千问 API | 可换其他 OpenAI 兼容接口 |
| 语音合成 | Edge TTS（自然、免费但非官方） | Piper 本地离线 |
| 唤醒 | 按回车/网页按钮 | openWakeWord 自定义中文唤醒词 |

### 6.3 安装

```bash
sudo apt install -y alsa-utils mpg123

python3 -m venv --system-site-packages .venv
source .venv/bin/activate
pip install -r requirements-voice.txt
```

下载 Vosk 中文小模型：

```bash
mkdir -p models
cd models
wget https://alphacephei.com/vosk/models/vosk-model-small-cn-0.22.zip
unzip vosk-model-small-cn-0.22.zip
cd ..
```

如果 `wget` 不存在：`sudo apt install wget unzip`。

### 6.4 配置 API

```bash
cp .env.example .env
nano .env
```

填入：

```dotenv
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=sk-你的key
LLM_MODEL=deepseek-chat
```

通义千问示例：

```dotenv
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_API_KEY=sk-你的key
LLM_MODEL=qwen-turbo
```

### 6.5 运行

先文字模式（不需要麦克风）：

```bash
python3 scripts/voice_chat.py --text
```

再语音模式（USB 麦克风 + 耳机/音箱）：

```bash
# 先看设备号和播放器
python3 scripts/voice_chat.py --check
arecord -l
aplay -l

# 假设 USB 麦克风是 card 1，3.5mm 耳机是 card 0
python3 scripts/voice_chat.py --voice \
  --audio-device plughw:1,0 \
  --playback-device plughw:0,0
```

`--playback-device` 需要 `mpg123`；如果只用 `ffplay`，它不能直接指定 ALSA 设备，建议安装 `mpg123` 或把系统默认声卡设为耳机。

语音模式的流程：

```text
按回车开始录音 4 秒
 → Vosk 转文字
 → 大模型回复
 → Edge TTS 生成 mp3
 → mpg123 播放
```

### 6.6 验收标准

- 文字模式能连续对话 5 轮；
- 语音模式说“你好”，8 秒内开始回应；
- 说“你叫什么名字”，回答符合人格设定；
- 断网/API 报错时，终端有明确提示，不崩溃；
- 播放 TTS 时不继续录音（半双工）。

### 6.7 省钱建议

- 人格提示词要求“回答不超过两句话”，TTS 不会念一大段；
- `max_tokens` 设 150–250；
- 常用回复（“我在”“网络断了”“好的”）本地缓存；
- 不在树莓派上跑 7B 本地大模型，体验会很差。

## 7. F5：人脸 + 语音联动

等 F1–F4 都稳定后，再做联动：

```text
检测到人脸
 → 识别名字
 → 如果 10 秒内没有打过招呼：
      “小明，你来啦。”
 → 进入聆听（按回车/网页按钮）
 → 对话
```

第一版**不要移动**，只做：

- 识别到熟人时打招呼；
- 陌生人说“你好，第一次见”；
- 说话时在终端/网页显示表情状态；
- 没有云台时，不做“转头”，避免增加故障点。

验收：

- 同一个人 30 秒内只主动打招呼一次，不刷屏；
- 识别失败时不乱叫名字；
- 语音和摄像头同时运行 10 分钟不崩溃；
- CPU 温度 < 80°C。

---

## 8. F6：网页/外壳

- 网页显示摄像头画面、识别名字、对话记录；
- 网页按钮代替回车，方便手机操作；
- 纸板/亚克力外壳先做，不急着 3D 打印；
- 摄像头略高于人脸，避免仰拍。

这样电机不会成为早期调试的干扰项。
