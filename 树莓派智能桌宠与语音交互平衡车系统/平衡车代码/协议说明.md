# 平衡车通信协议

树莓派（上位机）↔ STM32（下位机），HC-04 蓝牙串口，**9600 8N1**。

所有数据包用方括号包裹、逗号分隔，例如 `[go,1.40,0]`、`[s,-12,150,45,1,0,0,3,0,0,0]`。
车端解析在 `User/main.c` 主循环的 `BlueSerial_RxFlag` 分支里，
上位机解析在 `pi_files/car.py` 的 `Link._parse()`。

---

## 一、上位机 → 车

| 指令 | 含义 | 说明 |
|---|---|---|
| `[go,速度,转向]` | 前进/后退 | 速度单位 圈/秒，正前进负后退，硬限幅 ±5；转向 −1~+1 开环差速，一般给 0 |
| `[turn,角度]` | **相对**转向 | 正数右转，闭环在车上，转完自己停。`0` 等于取消。±360 限幅 |
| `[stop]` | 停运动 | **不关平衡**，车继续站着。演示中途停下用这条 |
| `[run,1]` / `[run,0]` | 远程启停平衡环 | 等同按 Key1。`[run,1]` 前必须把车扶正 |
| `[joystick,LH,LV,RH,RV]` | 遥控器 / 触摸屏摇杆 | `LV/25` = 目标速度（圈/秒），`RH/5` = 差速目标。500ms 收不到新包就自动停。手机 APP 和触摸屏遥控页都走这条 |
| `[slider,名称,值]` | 在线调参 | 见文末参数表 |
| `[plot,...]` | 蓝牙波形 | 默认关闭（`USE_PLOT=0`），开了会挤占遥测带宽 |

### 三条设计约定

1. **转向闭环在车上，不在树莓派。**
   蓝牙 10Hz 遥测 + 几十毫秒延迟，做闭环必然震荡。Pi 只说"转 90 度"，
   转到多少由车上的陀螺仪保证，掉几个包也不会转歪。

2. **`[stop]` 不关 RunFlag。**
   车要一直保持平衡站着。一条 `[stop]` 就把车放倒，是演示时最尴尬的场面。

3. **两种运动指令的生命周期不一样，所以车端分了 `MoveMode`：**

   | 模式 | 触发 | 停车条件 |
   |---|---|---|
   | `MOVE_JOY` | `[joystick]` | 500ms 收不到新包 |
   | `MOVE_PI` | `[go]` | 9 秒收不到任何运动指令（`CMD_TIMEOUT_MS`） |

   混在一起会出问题：摇杆的 500ms 判据会把 `[go]` 的目标清掉，车只跑半秒。

## 二、车 → 上位机（10Hz）

```
[s, 角度×10, 速度×100, 航向, 状态位, 差速×100, 差速PWM, 平均PWM, 倾角指令×10, 速度环积分, 角度环积分, 零点学习×10]
```

字段都乘了 10 或 100：蓝牙是文本协议，整数比小数省字节，也不会有 `0.2999999` 这种浮点尾巴。

| 序号 | 字段 | 单位 | 用途 |
|---|---|---|---|
| 1 | 角度 | 0.1° | 融合倾角，参与 PID 的那个值，平衡时应≈0 |
| 2 | 速度 | 0.01 圈/秒 | 两轮平均 |
| 3 | 航向 | 1° | GZ 积分，转向判据 |
| 4 | 状态位 | 位 | 见下表 |
| 5 | 差速 | 0.01 圈/秒 | 左−右 |
| 6 | 差速PWM | PWM | 转向实际出力 |
| 7 | 平均PWM | PWM | 平衡环实际出力 |
| 8 | 倾角指令 | 0.1° | 速度环输出，就是角度环的目标 |
| 9 | 速度环积分 | PWM | 松手后必须变号，才能把车刹停 |
| 10 | 角度环积分 | 原始 | 诊断用 |
| 11 | 零点学习量 | 0.1° | 自动校准累加了多少 |

### 状态位

| 位 | 值 | 含义 | 上位机该怎么做 |
|---|---|---|---|
| 0 | 1 | 运行中 | 为 0 就拒绝一切运动指令，提示"按车上 Key1" |
| 1 | 2 | 转向中 | 禁止叠新指令 |
| 2 | 4 | 跌倒锁 | 车摔过，只能按 Key1 复活，语音指令不敢复活它 |
| 3 | 8 | 陀螺零偏标歪 | 上电时车在动，航向每秒漂十几度。拒绝转向 |

## 三、实车标定步骤

烧录后按顺序做，一次做完不用再动。

### 1. 平衡（不动参数）
车扶正 → 按 Key1 → 松手。`apwm` 应在 ±10 内小幅波动、`角度` 稳在 0 附近。
若车往前跑，是 `ANGLE_OFFSET` 偏了：看 OLED 的 `aA:`，把 `#define ANGLE_OFFSET` 改成该读数。
自动校准（`ANGLE_AUTOCAL=1`）会在车走稳 1.5 秒后自己把残差学掉。

### 2. 航向方向（`YAW_GZ_SIGN`）
手拿车保持水平，**慢慢向右转 90°**，看遥测第 4 个字段（航向）：

- 变大 → `#define YAW_GZ_SIGN (+1.0f)` 不动
- 变小 → 改成 `(-1.0f)`

错了不会失控（0.8 秒方向自检会兜住"到不了目标"），但会出现"说右转实际左转"。

### 3. 转向手感
先发 `[turn,90]` 试一次，观察：

| 现象 | 调什么 |
|---|---|
| 转过头（冲过 90° 再回来） | `YAW_OUTMAX` 调小（14 → 10），或 `YAW_KD` 调大（0.18 → 0.25） |
| 差 5~10° 就不动了 | 静摩擦。`YAW_KI` 调大（0.25 → 0.4） |
| 转得特别慢 | `YAW_OUTMAX` 调大（14 → 18） |
| 数值到不了目标、越转越远 | `YAW_DIR` 改符号 |

转速参考：Pi 端按 **56°/s** 估算等待时间，`YAW_OUTMAX=14` 大约就是 60~70°/s，
在这个量级附近就行，差别不影响功能（车端有自己的超时和到位判据）。

### 4. 前进
`[go,1.4,0]` → 车应匀速前进，`速度` 字段稳定在 140 左右（即 1.4 圈/秒）。
若越跑越快 → 编码器符号反了，看 `SPEED_SIGN_L/R` 的注释。
`[stop]` 后应在 0.5 秒内停下。

## 四、参数速查

| 宏 | 默认 | 作用 |
|---|---|---|
| `YAW_KP` | 0.45 | 航向误差 → 差速 PWM |
| `YAW_KI` | 0.25 | 积分，消静摩擦死区（只在 \|误差\|<25° 时累加） |
| `YAW_KD` | 0.18 | 阻尼，防过冲 |
| `YAW_OUTMAX` | 14 | 差速上限，决定最快转多快 |
| `YAW_DONE` | 2.5 | 到位阈值（还要同时满足角速度 <8°/s） |
| `YAW_DIR` | −1.0 | 差速 PWM 的转向方向 |
| `YAW_GZ_SIGN` | +1.0 | 航向坐标系（右转为正） |
| `YAW_TIMEOUT_MS` | 12000 | 单次转向超时 |
| `CMD_TIMEOUT_MS` | 9000 | `[go]` 断链自动停 |
| `TEL_DIV` | 2 | 遥测分频，2 → 10Hz |
| `USE_PLOT` | 0 | 关掉蓝牙波形，把带宽留给遥测 |
